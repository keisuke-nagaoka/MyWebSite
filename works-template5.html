- Slackbot開発 -

IT企業における新入社員研修において、ガイダンス投稿用のツールをPythonにて開発、導入を行った。

担当

要件定義・詳細設計・開発・運用保守

使用技術

Python, Slack API

ターゲット

IT企業の新入社員研修担当者

システムについて

Slackの標準予約投稿だと1件ずつ投稿するか、毎日同じ投稿内容であればリマインダーを使うが、微妙に文言が違ったりするなど、煩雑な投稿を行う必要があった。
そこでCSVに投稿するチャンネル、投稿日時、投稿内容を入力し、SlackAPIを介して一括で投稿・削除を行うbotを開発した。
