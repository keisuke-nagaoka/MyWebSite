- 問い合わせ管理システム -

TypeScript / Node.js / Express / MySQL を用いて個人開発しました。
問い合わせの一覧表示・詳細表示・登録・編集・更新などのCRUD機能を実装しています。
フロントエンドから直接データベースを操作するのではなく、Expressで構築したREST APIを介してMySQLのデータを取得・登録・更新する構成としています。

API / Express

Expressで問い合わせ情報を操作するAPIエンドポイントを実装し、ブラウザからのHTTPリクエストに応じてMySQLへアクセスします。
例えば問い合わせ一覧を表示する際は、フロントエンドからAPIへGETリクエストを送り、ExpressがMySQLから問い合わせデータを取得してJSON形式で返却します。
登録や更新についても同様に、POSTやPUTなどのHTTPメソッドを使用してAPIへリクエストを送り、Express側で受け取ったデータをMySQLへ反映する構成です。
これにより、画面表示を担当するフロントエンド、業務処理・APIを担当するExpress、データ管理を担当するMySQLという形で役割を分離しています。

TypeScript / Node.js

バックエンドはNode.jsで実行し、開発言語にはTypeScriptを採用しました。JavaScriptに型情報を加えられるTypeScriptを使用することで、問い合わせデータやAPI処理の型を明確にし、開発時の型チェックによって実装ミスを検出しやすい構成としています。

データベース

データベースには Amazon RDS for MySQL を使用しています。アプリケーションを稼働させるEC2とデータベースを分離し、ExpressからRDSへ接続して問い合わせデータを管理しています。
RDSへの接続はインターネットへ直接公開せず、EC2から必要なMySQL通信のみを許可するセキュリティグループ構成としています。また、アプリケーションからRDSへの接続にはTLSを使用しています。

Docker / AWS

アプリケーションはDockerイメージとして構築し、Amazon EC2上のDockerコンテナとして稼働させています。
外部からのHTTPSアクセスはNginxで受け付け、リバースプロキシによってExpressコンテナへ転送しています。
