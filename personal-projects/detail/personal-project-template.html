- スクロールゲーム -

Go言語を用いて、横スクロール型の2Dアクションゲームを個人開発しました。
プレイヤーキャラクターをキーボードで操作し、ステージ上を移動・ジャンプしながら進んでいくシンプルなスクロールゲームです。
ゲーム開発にはGo向けの2Dゲームエンジン Ebitengine を使用し、キャラクターの描画・キー入力・座標管理・画面スクロール・当たり判定など、ゲームを構成する基本的な処理を実装しています。

Go / Ebitengine

開発言語にはGoを使用し、ゲームエンジンとしてEbitengineを採用しました。
Ebitengineでは、ゲームの状態更新を行う処理と画面描画を行う処理を分離して実装できます。
このゲームでは、キー入力に応じてプレイヤーの座標や移動速度を更新し、そのゲーム状態をもとにキャラクターやステージを画面へ描画しています。
このようなゲームループを通して、通常のWebアプリケーションとは異なる、リアルタイムに状態を更新し続けるプログラムの実装を経験しました。

WebAssembly / ブラウザ実行

Goで作成したゲームをブラウザ上でも実行できるよう、WebAssembly（Wasm）向けにビルドしています。
これにより、専用の実行ファイルをインストールすることなく、ポートフォリオサイトへアクセスするだけで実際にゲームを操作できるようにしています。

Docker / AWS

WebAssemblyとしてビルドしたゲームをDockerコンテナで配信し、Amazon EC2上で稼働させています。
外部からのアクセスはNginxで受け付け、HTTPS経由でゲームを公開しています。
ゲームそのものの開発だけでなく、Goによる実装からWebAssemblyへのビルド、Docker化、AWS EC2へのデプロイ、Nginx・HTTPSによるWeb公開まで一通り構築しました。
